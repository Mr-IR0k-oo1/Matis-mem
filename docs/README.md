# Matis-mem Architecture Book

This directory contains the comprehensive architectural documentation for Matis-mem.

## Structure

- **[01-overview/](01-overview/)**: Vision, goals, and the problem space.
- **[02-architecture/](02-architecture/)**: High-level system design and core components.
- **[03-memory/](03-memory/)**: Memory engine, promotion, and retrieval logic.
- **[04-event-system/](04-event-system/)**: Event models, types, and the event bus.
- **[05-capture/](05-capture/)**: Adapters for AI, Git, Shell, and other sources.
- **[06-storage/](06-storage/)**: Persistence strategies (SQLite, Vector, etc.).
- **[07-query-engine/](07-query-engine/)**: Context building and search logic.
- **[08-api/](08-api/)**: External interfaces (REST, WebSocket, MCP).
- **[09-ui/](09-ui/)**: TUI and dashboard design.
- **[10-development/](10-development/)**: Roadmap, testing, and contribution guidelines.
- **[diagrams/](diagrams/)**: System diagrams and flowcharts.
- **[adr/](adr/)**: Architecture Decision Records.
