# Contributing to Matis-mem

## Getting Started
1. Fork the repository.
2. Install Rust (latest stable).
3. Run `cargo test` to ensure the baseline is stable.
4. Join the architecture discussions in the `docs/` or issues.

## Contribution Workflow
1. **Design First**: If proposing a major change, start by writing an Architecture Decision Record (ADR) in `docs/adr/`.
2. **Implement**: Write the code, following the `Coding Style`.
3. **Test**: Add unit and integration tests for your changes.
4. **Document**: Update relevant sections of the architecture book.
5. **PR**: Submit a pull request with a clear description of the "Why."

## Areas of Focus
- **Adapters**: Help us support more AI tools, IDEs, and shells.
- **Memory Engine**: Improve the scoring and distillation algorithms.
- **UI/UX**: Enhance the TUI and help build the web dashboard.
- **Integrations**: Build official plugins for your favorite editors.

## Code of Conduct
Be respectful, professional, and focus on technical excellence. Matis-mem is a tool built by engineers, for engineers.
